📱 手机号去重工具 - 使用说明
================================

🎯 这个工具能做什么？
--------------------
把 txt/excel 里的手机号批量导入、自动跟历史库去重、下载不重复的部分。

🚀 怎么使用？
------------
1. 双击 start.bat
2. 浏览器会自动打开工具页面（http://localhost:8765）
3. 把 txt/excel 文件拖到虚线框里（或点击虚线框选文件）
4. 上传完成后，页面顶部会弹出绿色横幅
5. 点「⬇️ 下载本次不重复」按钮，即可下载本次新增的手机号

⚠️ 注意事项：
------------
- 手机号必须是 11 位数字（中国大陆手机号格式）
- 支持格式：.txt / .xlsx / .xls / .csv
- 文件大小上限 50MB
- 不合法的行会自动跳过，结果里会显示跳过数量
- 关闭浏览器不会停止服务，需要停止时关闭命令行窗口

💾 我的数据存在哪里？
-------------------
C:\Users\<您的用户名>\AppData\Roaming\手机号去重工具\
├── data\
│   ├── history.db        ← 手机号库（不要删，删了数据就没了！）
│   └── exports\          ← 历史导出文件
└── ...

🔧 遇到问题怎么办？
-----------------
1. 端口 8765 被占用？
   → 编辑 start.bat，把 PORT=8765 改成别的端口（如 8888）
   → 浏览器访问 http://localhost:8888

2. 启动后浏览器没自动打开？
   → 手动打开浏览器，访问 http://localhost:8765

3. 杀毒软件报警告？
   → 添加信任即可，工具不含恶意代码
   → PyInstaller 打包的程序常被误报

4. 服务卡住或无响应？
   → 关闭命令行窗口
   → 重新双击 start.bat

5. 想清空数据重新开始？
   → 停止服务后，删除 AppData\Roaming\手机号去重工具\data\history.db
