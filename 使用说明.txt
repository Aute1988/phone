📱 手机号去重工具 - 使用说明
================================

🎯 这个工具能做什么？
--------------------
把 txt/excel 里的手机号批量导入、自动跟历史库去重、下载不重复的部分。

🚀 怎么使用？
------------
1. 解压 zip 后，进入 phone_dedup_tool 文件夹
2. 双击【phone_dedup_tool.exe】（主程序，绿色版，不需要安装任何东西）
   ⚠️ 不要双击 start.bat！那个是开发用的
3. 浏览器会自动打开工具页面（http://localhost:8765）
4. 把 txt/excel 文件拖到虚线框里（或点击虚线框选文件）
5. 上传完成后，页面顶部会弹出绿色横幅
6. 点「⬇️ 下载本次不重复」按钮，即可下载本次新增的手机号

⚠️ 注意事项：
------------
- 手机号必须是 11 位数字（中国大陆手机号格式）
- 支持格式：.txt / .xlsx / .xls / .csv
- 文件大小上限 50MB
- 不合法的行会自动跳过，结果里会显示跳过数量
- 关闭浏览器不会停止服务，需要停止时关闭控制台窗口
- 第一次运行时，data 目录会自动创建在程序同目录下

💾 我的数据存在哪里？
-------------------
数据存在程序同目录的 data\ 文件夹，方便您备份：

📁 phone_dedup_tool\
├── phone_dedup_tool.exe
├── data\                    ← 【数据在这里】
│   ├── history.db           ← 手机号库（不要删，删了数据就没了！）
│   ├── history.db-wal       ← 临时日志（系统会自动管理）
│   └── exports\             ← 历史导出文件
└── ...

📦 如何备份数据？
-----------------
直接压缩整个 phone_dedup_tool 文件夹即可！
换电脑/重装系统后解压到任意位置，数据全在。

🔧 遇到问题怎么办？
-----------------
1. 端口 8765 被占用？
   → 关闭程序后，按 Win+R 输入 cmd 回车
   → 输入：netstat -ano | findstr :8765
   → 找到占用进程的 PID，去任务管理器结束它
   → 或者修改 server.py 里的 PORT 后重新打包

2. 启动后浏览器没自动打开？
   → 手动打开浏览器，访问 http://localhost:8765

3. 杀毒软件报警告？
   → 添加信任即可，工具不含恶意代码
   → PyInstaller 打包的程序常被误报

4. 程序闪退/打不开？
   → 右键 phone_dedup_tool.exe → 属性 → 勾选"以管理员身份运行"
   → 或者检查 data 目录是否有写入权限

5. 想清空数据重新开始？
   → 关闭程序后，删除 data\history.db
   → 下次启动会自动重建

6. 想迁移到另一台电脑？
   → 压缩整个 phone_dedup_tool 文件夹
   → 在新电脑解压后双击 exe 即可（数据完整保留）
